# Cześć, jestem Kamil! 👋

[English version](README.md)

Jestem backend developerem pracującym głównie w PHP i Symfony. Projektuję i utrzymuję API, logikę domenową oraz integracje z systemami zewnętrznymi — a do tego prowadzę całą ścieżkę wdrożenia tego, co tworzę: od Dockerfile'a, przez CI/CD, po reverse proxy i TLS na serwerze. Kiedy projekt potrzebuje frontendu, robię go również.

## O mnie

Komercyjnie tworzę aplikacje webowe od 2020 roku, w tym integracje platformy e-commerce dla [Shoper](https://www.shoper.pl/) (dreamcommerce), obecnie pracuję jako backend developer. Moje mocne strony to architektura backendu, dyscyplina testowania i integracje API. Każdy z poniższych projektów działa na infrastrukturze, którą sam administruję.

## Wyróżnione projekty

- **[CryptoPulse](https://github.com/Tolemak/CryptoPulse_BackendDemo)** — API w Symfony 8 agregujące ceny kryptowalut z Binance, Kraken i Coinbase. Redis jako główny magazyn danych, a nie tylko cache, alerty progowe dostarczane webhookiem, rate limiting per giełda i per klient, odpytywanie zabezpieczone blokadą. [Demo na żywo](https://crypto-pulse.tolemak.pl/)
- **[LectureBackend](https://github.com/Tolemak/LectureBackend_BackendDemo)** — REST API w Symfony do zarządzania wykładami i zapisami studentów. Architektura warstwowa (domena / persystencja / API), pokrycie testami >88%, specyfikacja OpenAPI.
- **[FileActions](https://github.com/Tolemak/FileActions_BackendDemo)** — backend w Symfony do wsadowego przetwarzania plików (zmiana rozmiaru, konwersja, kompresja) oparty na Imagick. Zdockeryzowany, z zestawem testów PHPUnit. [Demo na żywo](https://file-actions.tolemak.pl/)
- **[Mathema](https://github.com/Tolemak/mathema)** — interaktywna aplikacja do nauki matematyki z backendem Node/Express + SQLite obsługującym wspólną tablicę wyników. [Demo na żywo](https://mathema.tolemak.pl/)
- **[Portfolio](https://github.com/Tolemak/portfolio-react)** — strona tego portfolio: React, TypeScript, Vite, dwujęzyczna (PL/EN), CI/CD na własny VPS. [Strona na żywo](https://kamil-galkowski.pl)

## Technologie, z którymi pracuję

- **Backend:** PHP, Symfony, Node.js/Express, Python
- **Bazy danych i magazyny:** MySQL, PostgreSQL, SAP SQL Anywhere, MongoDB, SQLite, Redis
- **Testowanie:** PHPUnit, Vitest
- **Infrastruktura:** Docker, GitHub Actions, Linux VPS — Apache, reverse proxy, SSL, zadania cykliczne
- **Frontend:** JavaScript/TypeScript, React, Vite
