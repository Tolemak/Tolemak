# Cześć, jestem Kamil! 👋

[English version](README.md)

Jestem Fullstack Developerem z pasją do budowania solidnych aplikacji webowych i integrowania API. Dzięki doświadczeniu w PHP, Symfony, JavaScript, Bootstrap, Python i SQL, lubię wnosić kreatywne rozwiązania do złożonych problemów i dostarczać wysokiej jakości oprogramowanie.

## O mnie

Mam kilka lat komercyjnego doświadczenia w tworzeniu aplikacji webowych, w tym integracje platformy e-commerce dla [Shoper](https://www.shoper.pl/) (dreamcommerce), a do tego szereg własnych projektów obejmujących backendowe API, aplikacje frontendowe i infrastrukturę. Moje mocne strony to architektura backendu, dyscyplina testowania oraz integracje API — zajmuję się też projektowaniem frontendu i wdrożeniem/CI dla wszystkiego, co tworzę.

## Wyróżnione projekty

- **[LectureBackend](https://github.com/Tolemak/LectureBackend_BackendDemo)** — REST API w Symfony do zarządzania wykładami i zapisami studentów. Architektura warstwowa (domena / persystencja / API), pokrycie testami >88%, specyfikacja OpenAPI.
- **[FileActions](https://github.com/Tolemak/FileActions_BackendDemo)** — backend w Symfony do wsadowego przetwarzania plików (zmiana rozmiaru/konwersja/kompresja), zdockeryzowany, z zestawem testów PHPUnit. [Demo na żywo](https://file-actions.tolemak.pl/)
- **[Portfolio](https://github.com/Tolemak/portfolio-react)** — strona tego portfolio: React/TypeScript/Vite, dwujęzyczna (PL/EN), jasny/ciemny motyw, CI/CD na własny VPS. [Strona na żywo](https://kamil-galkowski.pl)
- **[Mathema](https://github.com/Tolemak/mathema)** — interaktywna aplikacja do nauki matematyki z prawdziwym backendem (Node/Express + SQLite) obsługującym wspólną tablicę wyników. [Demo na żywo](https://mathema.tolemak.pl/)
